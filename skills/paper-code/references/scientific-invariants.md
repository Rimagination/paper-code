# 科学语义：按受影响路径查阅

先辨认实际计算与调用关系，再选读相关章节；审计只作静态核对。不要机械填满所有领域，也不要把没有查看的关联当作不适用。这里列检查线索，不替作者选择研究方法。

## 1. 样本、缺失与配对

保留纳入/排除条件、按行/按组过滤、完整配对、重复样本、权重、排序、ID 对齐和连接基数。核对样本 ID、数量、分组大小、重复键与前后对应关系。

区分 None/NaN/NA、有效零值、空字符串、无穷与哨兵值；检查空输入、最小样本。分别过滤前测与后测数组会打散配对。

```python
# 只有 None 缺失，零有效
valid = [x for x in values if x is not None]
# 不等价：会丢弃零值
valid = [x for x in values if x]
```

## 2. 统计定义

保留 ddof、样本/总体方差、分母、单/双侧检验、置信区间、阈值、多重比较校正及加权方法；用可手算小例子、已批准参考值与实际定义核对。

将 n - 1 改成 n，或用库的默认 ddof 替代原定义，即使差异很小也属方法变化。论文与实现矛盾时转 §9，不顺手统一。

## 3. 数值与求值顺序

保留 dtype、精度、隐式转换、形状、广播、索引、累加/求值次序及所用算法。检查非有限值、NaN 比较规则、极值和预先确定的误差标准。

更短的 sum、向量化或并行归约不自动等价；硬件/库版本也可能影响低位数。保留原次序；确需变化时独立授权并预定领域合理容差，不能事后放宽。

## 4. 随机过程与机器学习

保留 RNG 类型、状态、种子、调用次数与次序、数据划分、批次顺序、预处理拟合范围、早停、评价集及并行非确定性。核对分割/采样索引和状态；不能确定性重现时按预定方案评估多次运行波动。

批量随机调用可能改变随机流消耗；同一个 seed 不保证不同实现等价。不要新增或挑选种子制造一致，不让预处理跨训练/测试边界造成泄漏。

## 5. 时空与单位

保留 CRS、轴顺序、单位、分辨率、投影、重采样、空间掩膜、时区、历法及时间聚合边界。核对元数据、关键像元/观测与时间戳；不能只凭图看起来一致判断等价。

## 6. 实验契约与工具消费

保留默认值、CLI 参数/退出码、路径、公开函数、返回字段/顺序、输出文件命名、日志和异常；核对消费者、接口测试及命令帮助。兼顾动态引用和外部调用，未找到调用不等于无用。

docstring 可能用于帮助文本、反射或 doctest；类型注解、装饰器与导入可能被运行时读取或注册。shebang、编码声明、类型检查/覆盖率指令和调度器注释也不是普通说明。不能确认无影响时按可执行改动验证，不因 diff 只在字符串或注释中而降级。

## 7. 图表

保留底层数据、坐标尺度、筛选、分组、误差线定义、标签与图例映射、颜色所表达的科学含义。先比较图源数据与标注，再做视觉检查；像素相似不能证明数据相同。

检查执行顺序、内核遗留状态、手改输出、缓存和相对路径。只有获授权且可隔离资源/输出时，才从空内核顺序执行副本；保留原 notebook，不把旧输出当成本轮复现。交付细节见 [验证协议](verification.md) §5。
